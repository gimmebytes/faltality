# Steering: Language

- Chat / conversation with the user MAY be in German.
- EVERYTHING else is always in English: specs (`.kiro/specs`), documentation,
  code, code comments, commit messages, PR titles and bodies, and any file
  committed to this repository.
- Do not switch repo artifacts to German just because the chat is in German.
- Verbatim content stays verbatim: identifiers, paths, log output, and quoted
  tool results are not translated.
